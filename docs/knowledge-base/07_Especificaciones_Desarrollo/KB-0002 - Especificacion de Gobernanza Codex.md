# KB-0002 - Especificacion de Desarrollo de la Gobernanza del Conocimiento en Repositorios Codex

## Estado
Pendiente de desarrollo.

## Proposito
Definir la relacion entre la Base de Conocimiento Corporativa y las carpetas docs/governance existentes dentro de cada repositorio Codex.

## Objetivo
Garantizar que el conocimiento especifico del desarrollo permanezca junto al codigo, mientras que el conocimiento institucional evolucione dentro de la Base de Conocimiento Corporativa.

## Alcance
Definir proposito de docs/governance, sincronizacion con la Base de Conocimiento, criterios para promover decisiones, gestion de iniciativas, alertas, lecciones aprendidas y pendientes estructurales.

## Principios
Cada repositorio mantiene su propia gobernanza.

La Base de Conocimiento consolida unicamente el conocimiento institucional.

No debe existir duplicidad innecesaria.

## Dependencias
KB-0001.

## Criterio para iniciar el desarrollo
Despues de finalizar KB-0001.
